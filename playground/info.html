                        Every chat() call appends a user message and the assistant reply, then re-sends

                            # 3 chat() calls → 6 messages (1 user + 1 assistant each)

                            # show_memory_size() prints len(messages) and total chars

Cost and latency grow with every turn — full history re-sent each call

langgraph_multiagent_parallel

                        
playground/multiagent/langgraph_multiagent_parallel.py

                    

                    
▼

                

                

                    

                        Parallel multi-agent research using a fan-out / fan-in pattern. Three
                        specialized researchers — tech, business, and risk — run concurrently as independent
                        LangGraph branches. Their outputs are merged by a reducer and fed to a synthesizer that
                        produces one coherent report.
                    


                    

                        multi-agent
                        parallel fan-out
                        Send()
                        reducer
                        LangGraph
                        fan-in synthesis
                    


                    

                        
How it works

                        

                            # fan_out returns Send() objects — LangGraph runs them concurrently

                            def fan_out(state) -> list[Send]:

                                return [Send("tech_researcher", …), Send("business_researcher", …), Send("risk_researcher", …)]

                            

                            # Annotated reducer APPENDS each branch's output — no overwrite

                            research_outputs: Annotated[list[str], operator.add]

                            

                            # All branches converge — synthesizer waits for all three

                            builder.add_edge("tech_researcher", "synthesizer")

                            builder.add_edge("business_researcher", "synthesizer")

                            builder.add_edge("risk_researcher", "synthesizer")
                        

                    


                    

                        

                            

                            
Send() is the fan-out mechanism — each call spawns an independent concurrent branch with its own state slice

                        

                        

                            

                            
Annotated[list, operator.add] is the reducer — parallel writes append safely instead of overwriting each other

                        

                        

                            

                            
Parallel nodes must return dict, not the full state type — returning full state causes a race condition where the last writer wins

                        

                        

                            

                            
Synthesizer token budget is RESEARCHER_MAX_TOKENS * NUMBER_OF_RESEARCHER — it ingests all three outputs combined
